02

Think like a programmer

Period 1 · 10 minutes · learn

Every program, from a robot to a game, is built from 3 ideas.

1 · SequenceDo things in order.
wake up get dressed go to school
2 · Condition (if / else)Make a decision.
IF it is raining: take an umbrella ELSE: take sunglasses
3 · LoopRepeat an action.
REPEAT 10 times: jump
🤖 AI and coding

AI can help write code, and explain errors. But AI code can have bugs too. A coder always tests the code and understands it. Copying code you don't understand is not coding.

Debug like a pro

Period 1 · 10 minutes · spot, predict, fix

These are the steps of a smart classroom. Which idea is each one?

2 · Predict
3 · Bug report: “The fan stays ON after everyone goes home.”
1 IF temperature > 28: 2 fan = ON 3 ELSE: 4 fan = OFF
4 · Bug report: “The light turns ON in the middle of a sunny day.”
1 IF room_dark OR room_occupied: 2 light = ON 3 ELSE: 4 light = OFF
Remember

AND: both must be true. OR: one is enough. One small word can make a whole program wrong.
